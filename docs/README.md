# Game Talk Show — Cozinhando com a Klara

Site gamificado para acompanhar receitas, tarefas, pontos e recompensas da Chef Klara.

## Stack
- **Frontend:** HTML + CSS + JavaScript puro (GitHub Pages)
- **Backend:** Supabase (PostgreSQL + Auth + Storage)
- **E-mail:** SendGrid (via Edge Functions — futura implementação)

## Estrutura
- `docs/` → arquivos do site publicados no GitHub Pages
- `sql/` → scripts SQL para o Supabase
- `docs-projeto/` → documentação técnica
